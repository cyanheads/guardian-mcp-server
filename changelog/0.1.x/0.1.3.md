# 0.1.3 — 2026-08-21

Maintenance pass: `@cyanheads/mcp-ts-core` `^0.10.6` → `^0.12.3`, dependency refresh, recovery-hint wiring.

## Added

- **Recovery hints on the wire** — every declared contract reason now transmits its hint as `data.recovery.hint` via `ctx.recoveryFor()`: `guardian_search` (`invalid_date`, `no_results`), `guardian_browse` (`missing_section_id`, `section_not_found`, `missing_tag_id`, `tag_not_found`), and the service-level HTTP annotations (`unauthorized`, `not_found`, `section_not_found`, `api_error`). The framework mirrors the hint into `content[]` text.
- **Supply-chain guard** — `bunfig.toml` blocks packages published less than 3 days ago (`minimumReleaseAge`) and runs the Socket security scanner on install.
- **Dependency-specifier gate** — devcheck rejects floating specifiers (`latest`, `*`, dist-tags) in `package.json` and `bun.lock`.
- **Community health files** — `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `FUNDING.yml`, and `.gitattributes`.

## Changed

- **SDK v2 runtime** — the framework serves protocol revision 2026-07-28 alongside the 2025 era, declares strict tool inputs (`additionalProperties: false` at the root), advertises the error envelope in `outputSchema`, dual-sinks `ctx.log` to the client, and backs `resources/subscribe`.
- **Service passes handler `ctx` directly** to `fetchWithTimeout`/`withRetry` — the `makeReqCtx` shim is gone under the unified `RequestContext`; HTTP error annotation resolves each tool's declared recovery hint before rethrowing.
- **TypeScript ^7.0.2** with a tsconfig split — `tests/` typechecks for the first time; fixture reads narrowed under `noUncheckedIndexedAccess`.
- **Docker** — base images `oven/bun:1.3` → `1.4.0`, build stage pinned to `$BUILDPLATFORM` so multi-arch builds run natively instead of under QEMU, BuildKit cache mounts, and `--omit=peer` on the production and OTEL installs.
- **Metadata** — descriptions carry a "STDIO or Streamable HTTP." transport suffix across `package.json` and the bundle/plugin manifests; author fields canonicalized; codex plugin `longDescription` populated.
