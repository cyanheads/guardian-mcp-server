# 0.1.2 — 2026-06-12

Framework adoption pass on `@cyanheads/mcp-ts-core` `^0.10.6`, with the enrichment, packaging, and identity primitives it brings.

## Added

- **`totalCount` enrichment** — `guardian_search` and `guardian_browse` now publish the upstream total via `ctx.enrich.total()`, disclosing how many results exist beyond the capped page.
- **`createApp({ name, title })`** — server identity set explicitly to `guardian-mcp-server` instead of relying on the scoped-package name fallback.
- **Dockerfile `HEALTHCHECK`** — liveness probe hits the framework `/healthz` endpoint via Bun's `fetch` (no `curl`/`wget`), plus an `APP_VERSION` build arg wired to the `org.opencontainers.image.version` OCI label.
- **`scripts/clean-mcpb.ts`** — post-pack bundle cleaner wired into the `bundle` script; runs `mcpb clean` then strips dependency-shipped agent-doc entries (`skills/`, `.claude/`, `.agents/`, `SKILL.md`) nested under `node_modules/` that root-anchored `.mcpbignore` patterns cannot reach.

## Changed

- **Error codes** — `missing_section_id`, `missing_tag_id` (`guardian_browse`) and `invalid_date` (`guardian_search`) now resolve to `JsonRpcErrorCode.ValidationError` instead of `InvalidParams`.
- **`.mcpbignore`** — root dev-dir patterns anchored with a leading `/` so an unanchored `skills/` no longer also strips runtime `node_modules/*/skills/` paths.
- **`scripts/lint-packaging.ts`** — adds bundle-content guards (anchored-pattern checks, runtime-path protection, post-bundle agent-doc assertion) and a `createApp()`/manifest identity check.
- **`scripts/check-framework-antipatterns.ts`** — new `z.coerce.boolean()` env-flag rule (recommends `z.stringbool()`) and comment-line filtering so JSDoc that names an antipattern is not flagged as a usage.

### Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.19 → ^0.10.6
- `@types/node` ^25.6.0 → ^25.9.3
