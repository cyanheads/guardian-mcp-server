# 0.1.1 — 2026-06-01

MCP server for The Guardian Open Platform. Requires a free `GUARDIAN_API_KEY` (register at open-platform.theguardian.com). Provides full article body text — not just headlines — from the Guardian archive (1999–present).

## Added

- **`guardian_search`** — full-text archive search with optional section, tag, contributor, and date filters; returns articles with body text (HTML stripped, truncated at 2,000 words).
- **`guardian_get_article`** — fetch a single article by its path-slug ID with full body text.
- **`guardian_browse`** — browse by section or tag, list all sections, or search the tag taxonomy; supports pagination and date filtering.
- **README** — prerequisites, installation badges (Claude Desktop, Cursor, VS Code), tool reference, Docker usage, and configuration table.
- **`docs/tree.md`** — generated project structure.

## Security

- **API key always redacted** from error messages — `annotateHttpError` now redacts `GUARDIAN_API_KEY` from the error message even when the error already carries a typed reason, closing a path where the key could leak into structured error data returned to clients.
