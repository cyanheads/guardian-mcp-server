# 0.3.0 — 2026-11-11

## Added

- **`include_body`** skips body previews in search, `section_latest`, and `tag_latest` when set to `false`. Previews remain on by default and the page size limit is 50. ([#22](https://github.com/cyanheads/guardian-mcp-server/issues/22))
- **`guardian_get_article`** accepts Guardian web article URLs and returns keyword, series, and tone tags, plus first publication and last modification timestamps when available. ([#18](https://github.com/cyanheads/guardian-mcp-server/issues/18), [#24](https://github.com/cyanheads/guardian-mcp-server/issues/24))
- **`guardian-guide`** documents archive research and tag discovery. It is available as an MCP skill resource and ships with plugin installs, npm, MCPB, and Docker.

## Changed

- **Blank searches** omit the upstream query and use newest when relevance was requested. The response reports the applied sort and explains the switch. ([#21](https://github.com/cyanheads/guardian-mcp-server/issues/21))
- **Developer tooling** updates framework guidance, packaging and release checks, and the bug report form. The documentation points to the Guardian's current developer key limits.

## Removed

- **`error.data.body`** is no longer returned to clients. Use the error reason, HTTP status, recovery hint, and request ID for diagnosis. Redacted upstream bodies remain in server diagnostics. ([#20](https://github.com/cyanheads/guardian-mcp-server/issues/20))

## Fixed

- **Article text** preserves paragraph breaks, table rows and cells, and literal punctuation in CommonMark. Long previews retain one continuation after 2,000 words. Detail returns complete available text and names the content type when its body is missing. ([#19](https://github.com/cyanheads/guardian-mcp-server/issues/19))
- **Article and section lookups** reject wrong endpoint responses with typed nonretryable errors and preserve section, edition, and tag collection routes. Article HTTP 400 guidance points to the exact article ID. ([#17](https://github.com/cyanheads/guardian-mcp-server/issues/17), [#18](https://github.com/cyanheads/guardian-mcp-server/issues/18))
- **Search and browse recovery** rejects inverted dates locally, names active filters in empty searches, normalizes bare contributor slugs, and explains the Guardian's deep paging limit. ([#20](https://github.com/cyanheads/guardian-mcp-server/issues/20))
- **`list_tags`** applies `section_id` to taxonomy discovery. `list_sections` documents its unpaginated behavior. ([#23](https://github.com/cyanheads/guardian-mcp-server/issues/23))
