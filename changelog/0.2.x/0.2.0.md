# 0.2.0 — 2026-10-16

## Changed

- **Tool names:** Rename `guardian_search` to `guardian_search_articles` and `guardian_browse` to `guardian_browse_content`, without compatibility aliases ([#4](https://github.com/cyanheads/guardian-mcp-server/issues/4)).
- **Boolean tag filters:** Document AND, OR, NOT, grouping, and contributor composition in search and tag browsing ([#1](https://github.com/cyanheads/guardian-mcp-server/issues/1)).
- **Development guidance:** Sync framework skills for input repair, error envelopes, canvas bounds, and release verification.

## Fixed

- **`guardian_get_article`:** Return complete HTML-stripped text without the 2,000-word preview cap; search and browse continuations name `article_id` ([#14](https://github.com/cyanheads/guardian-mcp-server/issues/14)).
- **Truncation state:** Render each article's explicit `truncated` value on the text surface, including uncut and missing-body results ([#6](https://github.com/cyanheads/guardian-mcp-server/issues/6)).
- **HTTP diagnostics:** Use authored Guardian messages and canonical `status`/`body` fields without request URLs or duplicate diagnostic aliases ([#5](https://github.com/cyanheads/guardian-mcp-server/issues/5)).
- **Retry guidance:** Distinguish deterministic request/configuration failures from transient statuses, preserving status-specific codes, explicit retryability, and existing retry counts ([#11](https://github.com/cyanheads/guardian-mcp-server/issues/11)).
- **Calendar dates:** Reject impossible `from_date`/`to_date` values locally with `invalid_date`, including leap-year and century rules ([#12](https://github.com/cyanheads/guardian-mcp-server/issues/12)).
